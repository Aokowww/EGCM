# Data access and compliance

## ADNI data

This repository does **not** include raw data from the Alzheimer’s Disease Neuroimaging Initiative (ADNI).
To reproduce the ADNI analysis you must obtain access to ADNI under its data use terms, or use an
approved derivative dataset/package that you are permitted to use.

In this project, the example scripts rely on the `adnimerge` dataset provided via the `ADNIMERGE`
package. Please ensure your use complies with ADNI policies before sharing any derived datasets
(e.g., CSV exports).

**Recommendation:** keep all data products in `data/` and `results/`, which are excluded by `.gitignore`.
