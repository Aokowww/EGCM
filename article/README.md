# Working article

This directory contains the current full-length working article, its LaTeX
source, and the three figures required to compile it.

- [Compiled PDF](cluster_gcm_working.pdf)
- [LaTeX source](source/main.tex)
- [Figures](figures)

From `article/source`, compile with:

```bash
tectonic --outdir ../compiled main.tex
```

The manuscript distinguishes established results from proposed theory and
heuristic extensions. ADNI is restricted-access data; only reviewed aggregate
results are included in this repository. No participant-level records are
published here.
